# Manual validation evidence

These screenshots record manual comparisons between selected Alma Analytics
definitions and the generated review files. They supplement, but do not replace,
the automated fixture test under `tests/`.

- `Validation of filter_review for SLF accessions.png` checks a generated filter
  criterion against its Alma Analytics definition.
- `Validation of filter_review for UCR SCA exclusions.png` checks exclusion
  criteria in the filter review.
- `Validation that the saved_column_review export matches the Bin formula for
  Fulfillment - UCB Check-Out Type.png` checks a saved-column bin mapping.

These screenshots validate selected rule translations, not the complete output
schema or the separate campus exclusions-documentation publication step.
